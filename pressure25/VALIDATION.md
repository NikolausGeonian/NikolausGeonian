# 交付验证

- 目标文件：`Pressure25.exe`，Windows x64 GUI 程序，面向 Windows 10/11。
- 编译器：MinGW-w64 GCC 14.2，启用 `-Wall -Wextra -Werror`。
- 构建：`build.sh` 编译成功；资源与应用清单已嵌入。
- 运行依赖：仅 `COMCTL32.dll`、`GDI32.dll`、`KERNEL32.dll`、`msvcrt.dll`、`USER32.dll`，均为 Windows 系统库。
- Linux GCC 原生计算测试通过；Windows 计算测试程序在 Wine 10 中通过。
- Windows GUI 测试程序在 Wine 10 + Xvfb 中完成 **10 组测试，全部通过**：
  1. 默认表压、MPa，7 个文本框初始值均为 0。
  2. 编辑不计算，点击“计算数据”后得到正确结果。
  3. 修改输入会清除旧结果，压力升高显示负下降率。
  4. “清空数据”将全部 7 个文本框归零，重复点击行为一致。
  5. 零基准的下降率显示“无法计算”，压力结果仍显示。
  6. 非数字、非有限值、超范围温度和绝压被拒绝；有效小数可正常计算。
  7. 压力单位及绝对压力模式计算正确。
  8. 极大有限下降率使用科学计数法，不溢出显示缓冲区。
  9. 窗口高度受限时可滚动至下方内容。
  10. 界面恰有两个按钮、7 个文本框，结果只读，无示例数据功能。
- 实际交付的 GUI EXE 已在 Wine 中启动；使用中文替代字体检查了中文标签和控件布局。

验证范围：本次在 Linux 上交叉编译并使用 Wine 验证，尚未在实体 Windows 10/11 机器上运行。源码包中的 `build.bat` 可在 Windows MinGW-w64 环境重新编译并运行两套测试。
