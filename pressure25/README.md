# 压力温度换算（25 ℃）

Windows 10/11 64 位桌面程序。双击 `Pressure25.exe` 即可使用，无需安装 Python、.NET 或其他运行环境。程序在本地计算，不需要联网。

## 使用

1. 默认选择 **表压 / MPa**，输入两组压力与温度（℃）。第 1 组为初始读数，第 2 组为后续读数。
2. 点击 **计算数据**，显示两组换算至 25 ℃ 的压力，以及第 2 组相对第 1 组的下降率。
3. 点击 **清空数据**，全部 7 个文本框（4 个输入、3 个结果）立即归为 `0`。

启动时所有文本框均为 `0`，没有填充示例数据的功能。编辑输入或切换压力类型/单位会将旧结果归零，只有点击“计算数据”才产生新结果。结果框只读，可以选择和复制。

压力类型可选表压或绝对压力，单位可选 MPa、kPa、bar、Pa。切换单位只改变输入/输出的解释单位，不会自动换算已输入的数值；请按所选单位重新填写读数。小数使用英文句点，可输入负号和科学计数法。

## 计算定义

适用于**定容理想气体**的温度修正。使用绝对温度：`T(K) = t(℃) + 273.15`，目标为 `298.15 K`。

表压模式：

```text
P25 = (P + Patm) × 298.15 / (t + 273.15) − Patm
```

固定采用标准大气压 `Patm = 0.101325 MPa = 101.325 kPa = 1.01325 bar = 101325 Pa`。这是计算假设；若需要实际当地大气压修正，应调整程序中的 `atmospheres` 常量。

绝对压力模式：

```text
P25 = P × 298.15 / (t + 273.15)
```

下降率使用当前压力类型的换算结果：

```text
下降率（%）= (P1,25 − P2,25) / P1,25 × 100
```

表压模式显示的是**表压下降率**，不是气体物质量损失率或每单位时间的泄漏率。负值表示压力升高。若第 1 组换算压力小于或等于零，两个压力结果仍显示，下降率显示“无法计算”。所有温度必须大于 −273.15 ℃，绝对压力（表压加大气压）必须大于零。

换算压力显示 10 位有效数字，下降率通常显示小数点后 6 位，绝对值达到 1000000% 时使用 6 位有效数字的科学计数法。计算使用未格式化的数值，不使用显示后舍入的文本。

## 源码与编译

- `main.c`：中文 Win32 界面、输入校验和两个按钮。
- `pressure_calc.c` / `pressure_calc.h`：独立计算核心。
- `test_calc.c`：公式和边界测试。
- `test_gui.inc`：实际 Win32 控件测试，仅编译进测试程序。
- `app.rc` / `app.manifest`：版本、普通用户权限、DPI 和系统主题配置。
- `build.bat`：Windows MinGW-w64 编译并运行测试。
- `build.sh`：Linux MinGW-w64 交叉编译。

Windows 安装 64 位 MinGW-w64 并将其 `bin` 目录加入 PATH，在源码目录运行：

```bat
build.bat
```

Linux 安装 `gcc-mingw-w64-x86-64` 和 `binutils-mingw-w64-x86-64` 后，在源码目录运行：

```sh
bash build.sh
```

生成 `dist/Pressure25.exe`、`build/test_calc.exe`、`build/test_gui.exe`。纯计算测试也可直接在 Linux 上运行：

```sh
gcc -std=c11 -O2 -Wall -Wextra -Werror pressure_calc.c test_calc.c -lm -o /tmp/pressure25-test
/tmp/pressure25-test
```

GUI 测试需要 Windows 桌面，或 Wine + Xvfb。交付包中的 `VALIDATION.md` 记录实际完成的验证及其限制。
